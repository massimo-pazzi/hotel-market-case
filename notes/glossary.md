# Глоссарий гостиничных метрик

Основные показатели гостиничного рынка и бенчмаркинга отелей.

## Основные показатели

| Метрика | Что это | Формула |
|---------|---------|---------|
| **Occupancy** (загрузка) | Доля проданных номеров | проданные номеро-ночи / доступные номеро-ночи |
| **ADR** (Average Daily Rate) | Средняя цена проданного номера за ночь | выручка от номеров / проданные номеро-ночи |
| **RevPAR** (Revenue Per Available Room) | Выручка от номеров на один доступный номер | выручка от номеров / доступные номеро-ночи = ADR × Occupancy |
| **TRevPAR** (Total RevPAR) | Вся выручка отеля (номера + ресторан + услуги) на доступный номер | общая выручка / доступные номеро-ночи |
| **GOPPAR** | Валовая операционная прибыль на доступный номер | GOP / доступные номеро-ночи |

Номеро-ночь — один номер на одну ночь. Отель на 100 номеров за 30 дней
имеет 3 000 доступных номеро-ночей.

## Сравнение с конкурентами (бенчмаркинг)

**Comp set** (конкурентная группа) — 4–8 похожих отелей, с которыми
сравнивают свой отель.

| Индекс | Формула | Смысл |
|--------|---------|-------|
| **MPI** (индекс загрузки) | загрузка отеля / загрузка comp set × 100 | > 100 — отель заполняется лучше конкурентов |
| **ARI** (индекс цены) | ADR отеля / ADR comp set × 100 | > 100 — отель продаёт дороже |
| **RGI** (индекс RevPAR) | RevPAR отеля / RevPAR comp set × 100 | > 100 — отель зарабатывает больше, чем приходится на него пропорционально числу номеров |

RGI = MPI × ARI / 100.

## Будущий спрос

- **OTB** (On The Books) — брони, уже полученные на будущие даты. Hotel
  Advisors показывает загрузку на будущее.
- **Pickup** — сколько броней добавилось за период (например, за неделю).
- **Lead time** (глубина бронирования) — за сколько дней до заезда бронируют.
- **LOS** (Length Of Stay) — средняя длительность проживания.

## Разложение изменения RevPAR

Изменение RevPAR ≈ изменение ADR + изменение загрузки (в процентах, для
небольших изменений). Точно: (1 + ΔRevPAR) = (1 + ΔADR) × (1 + ΔOcc).
Пример: ADR +20%, загрузка −12,5% → 1,2 × 0,875 = 1,05 → RevPAR +5%.
